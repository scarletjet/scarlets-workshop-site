This is a nested creation

A page living at scarletsworkshop.live/pages/starter/ — the original nested-creation template, kept here for reference.

How this works

Every creation is a folder with its own index.html. The folder name becomes the web address automatically — no extra configuration needed. New creations belong under tools/, e.g. tools/color-picker/.

Add your own

Copy this template into tools/<your-slug>/, rename it (lowercase, hyphens instead of spaces), replace this page with your creation, and add an entry to the TOOLS array near the top of the <script> block in the homepage's index.html.

The back button

The button up top links to ../../ — two levels up, back to the hub. Keep one on every creation so visitors can always find their way home.
