How this works

Every creation is a folder inside pages/ (or apps/) with its own index.html. The folder name becomes the web address — no extra configuration needed.

Add your own

Copy this folder, rename it (lowercase, hyphens instead of spaces), replace this page with your creation, and add a link to it in the PAGES or APPS list on the homepage.

The back button

The button up top links to ../../ — two levels up, back to the hub. Keep one on every creation so visitors can always find their way home.
