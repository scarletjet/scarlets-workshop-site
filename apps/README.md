# apps/

Deployed apps live here — one folder per app, each with its own `index.html`.

Example: `apps/task-pilot/index.html` becomes `scarletsworkshop.live/apps/task-pilot/`

Copy `../pages/starter/` as a template, then add the app to the `APPS` list in the root `index.html` with the relative URL `apps/task-pilot/`.
