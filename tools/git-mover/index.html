Your Claude Code files travel with the repo. CLAUDE.md, .claude/, and .mcp.json are committed like any other file. But check your .gitignore — .claude/ is often excluded by default, so add it deliberately if you want it to come along.

From then on it's just git push / git pull and both machines stay in step. Commands are generated in your browser — nothing is sent anywhere.
